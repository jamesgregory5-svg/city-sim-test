# City Sim test

Playable original browser city scene (no Rockstar / GTA IP). Setting: Port Calloway, a fictional coastal city.

- Live: https://jamesgregory5-svg.github.io/city-sim-test/
- Password: same as Tour Sim
- **v0.5:** Get in any car (E), arcade driving (steer, brake, handbrake, reverse), chase camera, basic body damage. AI traffic stays in its lane and yields. Offline: [v0.5 release](https://github.com/jamesgregory5-svg/city-sim-test/releases/tag/v0.5).
- v0.4: Character creator, three save slots, walk/run, feet grounded to sidewalk vs road.

To play offline: download `city-sim.html` (or `city-sim-offline.zip`) from the [v0.5 release](https://github.com/jamesgregory5-svg/city-sim-test/releases/tag/v0.5) and open that file (no server). If you clone the repo, open `city-sim.html` for a self-contained copy; `index.html` is the live-site page and loads assets over HTTP. Enter the Tour Sim password, then New Game or Continue.
