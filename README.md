# City Sim test

Playable style tests for an original browser city scene (no Rockstar / GTA IP).

- Live: https://jamesgregory5-svg.github.io/city-sim-test/
- Password: same as Tour Sim
- **v0.2.1:** the playable app is a single self-contained HTML file (`index.html` / `city-sim.html`). It works on the live site **and** opened directly from a downloaded folder (`file://…`) with no web server. Offline build: see the [v0.2.1 release](https://github.com/jamesgregory5-svg/city-sim-test/releases/tag/v0.2.1).
- v0.2: faster style-view loading. Characters are the v0.1 set.

To play offline: download `city-sim.html` (or `city-sim-offline.zip`) from the release, or open `index.html` / `city-sim.html` from this repo. Enter the Tour Sim password, then pick Style A or Style C.
