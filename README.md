# City Sim test

Playable original browser city scene (no Rockstar / GTA IP). Setting: Port Calloway, a fictional coastal city.

- Live: https://jamesgregory5-svg.github.io/city-sim-test/
- Password: same as Tour Sim
- **v0.6:** A bigger Port Calloway — several blocks, intersections, traffic lights AI cars obey, more buildings and street props, more pedestrians and traffic, and a minimap. Offline: [v0.6 release](https://github.com/jamesgregory5-svg/city-sim-test/releases/tag/v0.6).
- v0.5: Get in any car (E), arcade driving, chase camera, basic body damage, lane traffic.
- v0.4: Character creator, three save slots, walk/run, feet grounded to sidewalk vs road.

To play offline: download `city-sim.html` (or `city-sim-offline.zip`) from the [v0.6 release](https://github.com/jamesgregory5-svg/city-sim-test/releases/tag/v0.6) and open that file (no server). If you clone the repo, open `city-sim.html` for a self-contained copy; `index.html` is the live-site page and loads assets over HTTP. Enter the Tour Sim password, then New Game or Continue.
