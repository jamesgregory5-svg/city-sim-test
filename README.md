# City Sim test

Playable style tests for an original browser city scene (no Rockstar / GTA IP).

- Live: https://jamesgregory5-svg.github.io/city-sim-test/
- Password: same as Tour Sim
- **v0.3:** Style A people are Quaternius Ultimate Modular Men/Women (adult proportions, varied skin, readable faces). Pedestrians stay on sidewalks and keep spacing; cars use right-hand travel lanes and park at the curb. Still a single self-contained HTML file (`index.html` / `city-sim.html`) that works on the live site **and** opened directly from a downloaded folder (`file://…`) with no web server. Offline build: see the [v0.3 release](https://github.com/jamesgregory5-svg/city-sim-test/releases/tag/v0.3).
- v0.2.1: single-file / `file://` fix. Characters were the v0.1 set.
- v0.2: faster style-view loading. Characters were the v0.1 set.

To play offline: download `city-sim.html` (or `city-sim-offline.zip`) from the release, or open `index.html` / `city-sim.html` from this repo. Enter the Tour Sim password, then pick Style A or Style C.
