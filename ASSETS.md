**v0.3 packaging:** Style A uses the Modular Men/Women packs (named Skin / Eye / Hair materials, adult ~1.8 m rigs), meshopt-compressed with unused animation clips stripped (Idle/Walk/Run kept). Style C still uses Kenney blocky characters. The playable app is a single self-contained HTML file so it works on the live site and via `file://` with no server. Cache API is optional.

**Not used:** Rockstar / GTA characters, names, maps, logos, or music. No likeness of real or famous people. Scene layout (asphalt, sidewalks, curbs, grass, lane paint) authored for this project. The v0.1 / v0.2 Ultimate Animated Character casuals are no longer used in Style A.
