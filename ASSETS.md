**v0.3.1 packaging:** Style A is the only look. People use the Modular Men/Women packs (named Skin / Eye / Hair materials, adult ~1.8 m rigs), meshopt-compressed with unused animation clips stripped (Idle/Walk/Run kept). The playable app is a single self-contained HTML file so it works on the live site and via `file://` with no server. Cache API is optional.

**Not used:** Rockstar / GTA characters, names, maps, logos, or music. No likeness of real or famous people. Kenney Animated Blocky Characters (formerly Style C) are no longer included. Scene layout (asphalt, sidewalks, curbs, grass, lane paint) authored for this project.
